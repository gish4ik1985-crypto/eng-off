# 🏝️ Остров английских слов

Игровой самоучитель английского для 2–4 классов (по мотивам Spotlight 2–4). Всё работает в браузере и **без интернета**, данные не отправляются никуда, прогресс хранится на самом устройстве.

## Как открыть на планшете

**Вариант 1. Через интернет (проще всего).** Включите GitHub Pages: репозиторий → *Settings* → *Pages* → *Build and deployment* → *Deploy from a branch* → ветка `main`, папка `/ (root)` → *Save*. Через минуту игра откроется по адресу `https://gish4ik1985-crypto.github.io/eng-off/`. Её можно добавить на главный экран (в Chrome: ⋮ → «Добавить на главный экран»; в Safari: «Поделиться» → «На экран Домой»).

**Вариант 2. Один файл без интернета.** Скачайте `english-selfstudy.html` и откройте в Chrome (Android) или Safari (iPad; сначала сохраните в «Файлы»).

## Что внутри

- 3 мира по учебникам Spotlight 2, 3 и 4 (80 локаций), боссы
- «Разведка» (определение уровня), «Тренировка» слабых мест, «Словарик» с карточками
- диалоги, рифмовки, аудирование, сказки и басни
- награды и ачивки, магазин (шляпы, питомцы, фоны)
- «Родителям»: недельный отчёт, семейные призы, перенос прогресса

## Важно

- Прогресс хранится в браузере **на каждом устройстве отдельно**. Перенести можно через «Родителям» → «Копия прогресса».
- Английский голос берётся из системы. Проверить: «Родителям» → «Проверить озвучку».

## Для правок

Слова и уроки лежат в `lessons*.js`, диалоги в `dialogs.js`, рифмовки в `songs.js`, аудирование в `audio.js`, сказки в `lessons5.js`. После изменений запустите `python build.py`, чтобы пересобрать единый файл `english-selfstudy.html`.
