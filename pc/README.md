# Фото для раздела «Компьютер»

Фотографии взяты с Wikimedia Commons (свободные лицензии: общественное достояние, CC0, CC BY-SA). Авторы и лицензии указаны под фото в игре и в `credits.json` (там же ссылки на страницы файлов).

Чтобы заменить фото на своё: положите `имя.jpg` в `photos/` (имена: setup, monitor, unit, keyboard, mouse, laptop, tablet, printer, headphones, microphone, webcam, usb, router) и поправьте подпись в `cworld.js` (объект `CRED`).
