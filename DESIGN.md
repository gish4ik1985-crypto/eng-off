# Идея: «Школа-off» + игра в одном приложении, адаптация под успеваемость

## Что есть
- **eng-off** (игра, ребёнок): английский, профили, награды, магазин, облако (семейный код, Google Apps Script).
- **school-off** (дневник, родитель): задания, оценки, замечания, расписание, итоги, «Подтянуть». Данные только в браузере, облака нет.

## Куда идём
Одно приложение, два режима за PIN-кодом:
- **Ребёнок** (по умолчанию): игра, миры-предметы (английский, потом математика, русский...).
- **Родитель** (PIN): дневник из school-off + отчёты по игре.

Общие данные: `children[]` = игроки; у каждого `subjects`, оценки/задания из дневника, прогресс в игре по предметам. Одно облако (тот же семейный код).

## Как система подстраивается под успеваемость
Модуль `adapt` (чистая логика, без DOM, с тестами). Вход → выход:

| Из дневника (родитель вносит) | Что делает игра |
|---|---|
| Оценки по предмету падают / средний балл < 3,5 | Предмет получает «фокус»: больше повторений, лёгкий старт, больше подсказок |
| Замечание «не знает таблицу умножения» (тема) | Тема попадает в «Тренировку» первой |
| Контрольная через N дней (задание с датой) | «Подготовка к контрольной»: мини-план на N дней в «Задании дня» |
| Домашка отмечена родителем «проверено» | Изумруды и ачивки (реальные дела → игровая валюта) |

| Из игры | Что видит родитель |
|---|---|
| Минуты, % верных по предмету и теме | Лист «Отчёт», строка в «Подтянуть» |
| Слабые темы (miss > 0 и box < 3) | «Темы из игры» рядом с темами из записей |

Внутри игры: «Задание дня» на карте (3 шага: повторить слабое, новый урок, любимое) вместо выбора из 10 кнопок; сложность и объём подбираются по фокусу и серии ошибок.

## Этапы
1. Каркас предметов в игре: `subjects[]`, мир = (предмет, уровень), общий движок упражнений, английский как первый предмет.
2. Слить дневник (school-off) в то же приложение, режим «Родитель» за PIN, общее облако.
3. Модуль `adapt` + «Задание дня» + награды за реальную домашку.
4. Второй предмет (математика 2–4 класс), контент можно готовить через z.ai.

## Открытые вопросы
- Объединять в одно приложение или оставить два с обменом данными через облако?
- Какой предмет вторым и по какому учебнику (Моро? Школа России?).
- Кто вносит оценки: только родитель (как сейчас), или ребёнок тоже может отметить «сделал»?
