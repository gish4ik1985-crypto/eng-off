# Инструменты

## Добавить учебник (PDF или фото) и распознать текст

Распознавание идёт **на этом компьютере** (Tesseract через `tesseract.js`): интернет нужен только в самый первый раз, чтобы скачать русский словарь, лимитов нет. Целая книга на 165 страниц — около полутора минут.

Один раз:

```
pip install pymupdf pillow
cd tools/ocr && npm install
```

Добавить книгу из PDF:

```
python tools/book.py "C:/путь/к/учебнику.pdf" rus3-1
```

Скрипт сделает страницы `books/rus3-1/pNNN.jpg` и текст `books/rus3-1/text.json`. Затем добавьте запись о книге в `books/books.js` (предмет, класс, название, оглавление) и выполните `python build.py`.

Для английских книг добавьте язык: `--lang eng+rus` (так распознана Spotlight 3).

Если страницы уже лежат в папке (например, фото `p000.jpg`, `p001.jpg`…), достаточно только распознавания:

```
node tools/ocr/ocr.js books/<id>            # пропускает уже распознанные страницы
node tools/ocr/ocr.js books/<id> --pages 10-20 --force
```

Игра берёт `text.json` автоматически: на странице книги сразу есть текст и кнопка «🎯 Задания по странице».
